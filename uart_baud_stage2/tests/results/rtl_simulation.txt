Stimulus independence and scope
------------------------------
The serial transmitter uses bit delay 1e9/requested_baud nanoseconds, rounded
only to the simulator's 1 ps time precision, with an asynchronous initial
phase. It does not copy the receiver's integer cycles-per-bit divisor.
Each baud test sends exactly one stop bit per frame without added gaps in
its 64-byte burst. BREAK is 30 bit periods in simulation; one malformed-stop
frame is separately tested, followed by explicit idle and recovery frames.
The FIFO test uses a software-style circular-queue reference model and
includes full simultaneous POP/push, dropped arrivals and sticky overflow,
held command toggles, clears, invalid configuration codes, all six readback
codes, resets, pointer wraps and events on both configuration/reset edges.

These are digital RTL results, not board measurements. They do not establish
Vivado synthesis/implementation success, timing closure, pin mapping, power,
real metastability behavior, physical TX timing, or sustained Python polling
throughput. Single-stop-bit fault injection here is simulated; the USB adapter
board experiment previously performed used BREAK. Stage 2 board validation
must be performed with the newly built matched .bit/.hwh pair.

Reproduce with Icarus in PATH, from uart_baud_stage2
--------------------------------------------------
iverilog -g2001 -Wall -s uart_diag_baud_core -o core_g2001.vvp rtl/uart_diag_baud_core.v
iverilog -g2012 -Wall -s uart_baud_event_fifo_tb -o fifo.vvp rtl/uart_diag_baud_core.v tests/uart_baud_event_fifo_tb.sv
vvp fifo.vvp
iverilog -g2012 -Wall -s uart_diag_baud_core_tb -o serial.vvp rtl/uart_diag_baud_core.v tests/uart_diag_baud_core_tb.sv
vvp serial.vvp
